# Data and saved-result provenance

## Application data

Original study: Wu, G. D., et al. (2011), *Linking Long-Term Dietary Patterns
with Gut Microbial Enterotypes*, Science 334, 105–108.
[DOI](https://doi.org/10.1126/science.1208344).

Variable-selection application/supplied representation: Chen, J., and Li, H.
(2013), *Variable selection for sparse Dirichlet-multinomial regression with an
application to microbiome data analysis*, Annals of Applied Statistics 7,
418–442. [DOI](https://doi.org/10.1214/12-AOAS592).

| File in `Real Data Analysis/Data/` | Contents |
|---|---|
| `combo_count_tab.txt` | Supplied microbiome counts and labels |
| `udiet.adj.scale.txt` | Supplied adjusted/scaled dietary covariates |
| `ffq.labels2.txt` | Dietary-variable codes and descriptions |

These are supplied analysis inputs, not raw sequencing reads. Preparation applies
the prevalence screen and average-linkage covariate reduction. The final matrices
have 98 individuals, 117 covariates and 30 genera. Preparation code and the fixed
graph are retained in the tempering helpers; prepared inputs are in
`New_simulations/dm_apt50k_fresh_v1/inputs/fresh.rds`.

All individuals and all retained genera enter the likelihood. Rebuilding from
saved results requires no imputation, sequencing processing or refitting.
Original study/data terms apply; confirm redistribution terms before release.
No new data license is inferred from their presence in the local package.

## Simulation results

Gaussian data are generated by the five drivers called by
`run_matched_gaussian_revision.ps1`; synthetic DM data by
`run_dm_online_adaptive_ablation.R`. Settings/seeds are defined in the drivers
and recorded in experiment manifests/provenance. Completed result directories
are identified in the root README.

Fitting-depth runs retain full fits and source snapshots. Primary synthetic DM
objects retain metrics, PIPs, coefficient summaries, traces and adaptation
summaries; their original folders did not contain separate generating-source
snapshots. The package preserves their original objects/manifests and does not
claim a retrospective exact source receipt.

## Real-data saved results

`dm_apt50k_fresh_slurm_v1/summary/summary.rds` contains all 12 ladders' retained
cold results, diagnostic summaries, runtime and source/checkpoint receipts.
Nearby CSV/report files are human-readable exports. This object supports all
reported displays, but does not contain every replica's continuation state.
Checkpoint hashes refer to remote originals; missing checkpoints are not
silently recreated. Remaining diagnostic qualifications are preserved.
